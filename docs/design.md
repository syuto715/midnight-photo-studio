# 午前零時の写真館 企画メモ

現在の部屋と過去の写真を見比べ、写真に混入した嘘を指摘して記録を修復する推理アドベンチャー。

## 検証したい核

- 長押しで現在と写真をブリンク比較する行為が気持ちいいか。
- 違和感をメモ化し、場所と根拠の2段階で嘘を指摘する瞬間に納得感があるか。
- フォールバック図形だけでも、5分以内に「見比べて気づく」体験が成立するか。

## 縦スライス

食堂の写真に5脚目の椅子がある。ただし壁の大鏡には椅子が4脚しか映っていない。写真上の嘘は椅子Eであり、根拠は鏡像の不一致。

## 拡張方針

部屋、写真、嘘、テキストはデータとして追加する。第2章以降に進む前に、犯人、動機、当夜のタイムライン、12枚の改ざん理由をまとめた真相ドキュメントを先に作る。
